# Product

## Register

product

## Users

One person using a custom browser new-tab page throughout the day. The primary job is opening a saved site or searching the web with almost no friction.

## Product Purpose

Provide a dependable, private-feeling home for personal bookmarks and web search. Success means the desired destination is reachable within a few keystrokes, while bookmark data remains easy to back up and recover.

## Brand Personality

Quiet, fast, personal.

## Anti-references

Busy dashboards, configuration-heavy productivity suites, decorative clutter, and interaction patterns that slow down routine navigation.

## Design Principles

1. Keep the primary search path immediate.
2. Prefer dependable browser-native behavior over elaborate controls.
3. Protect personal bookmark data from malformed input and storage failures.
4. Keep secondary configuration out of the main workflow.

## Accessibility & Inclusion

No formal compliance target. Preserve clear focus states and practical keyboard access, especially `/` to focus search and conventional search-result navigation.
